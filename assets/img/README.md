# Image assets

Images are grouped by their role on the site:

- `brand/`: logo, favicons, and touch icon
- `heroes/`: page banner photographs
- `photos/home/`, `photos/about/`, `photos/network/`, `photos/process/`, and `photos/services/`: content photographs
- `clients/`: client logos
- `ui/`: interface icons and cursors
- `decorations/`: background art and visual accents

Use lowercase kebab-case filenames that describe the visible subject or page role. Keep the original file format in the extension. If an image is shared by several pages, give it a subject-based name and keep one stable path rather than naming it for a single page.
